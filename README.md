# 2Box Cache Helper

面向《无尽的拉格朗日》Windows 客户端的非官方 2Box 共享资源与增量更新辅助工具。

**v0.2.0 下载包不包含 2Box 主程序、游戏资源、账号、登录数据库或本机配置。** 请从 [2Box 原作者发布页](https://github.com/Wei1030/2Box/releases) 单独获取 2Box 2.1.2。本项目不属于游戏官方，不绕过登录验证或游戏规则。

## 下载与升级

从本仓库 Releases 下载 `2box-cache-helper-v0.2.0-windows-x64.zip`，将包内文件夹的内容放到 `2Box.exe` 所在目录。`SharedCache.exe` 和 `_internal` 必须一起保留，无需安装 Python，不绑定发布者的盘符。

已有共享环境：关闭游戏和 2Box 后覆盖辅助工具文件，保留现有 `Env`、`SharedResources`、`bin`、个人配置与回滚记录。不要用旧版 `RefreshCache.exe` 重置共享环境，不要解压成另一套账号环境。

## 首次接入共享资源

本版本不会自动创建账号环境，也不会未经确认迁移或清理旧资源。全新用户需先自行创建固定环境、登录并退出；已有非共享环境需先备份账号和个人设置。选择一个资源完整、已经实际进入游戏的固定环境作为公共资源来源。

以环境 2 为例，在 2Box 目录打开终端，关闭官方客户端、所有多开游戏及 2Box 后执行：

```powershell
.\SharedCache.exe migrate --root . --environment 2
.\SharedCache.exe sync --root .
```

`migrate` 将该环境的四个资源目录移动到公共目录并创建目录连接，不额外复制整套资源；账号与窗口设置留在原环境。`sync` 以官方客户端的已更新缓存校验并同步公共资源，首次仍需完整扫描。应使用 NTFS 可写磁盘，并先确认官方客户端可以正常进入。

确认环境 2 实际进入且再次启动登录保持后，可接入其他已有、完整且基础版本一致的环境，例如：

```powershell
.\SharedCache.exe attach --root . --environment 3
.\SharedCache.exe sync --root .
```

其他环境原资源保留在迁移备份中，本版本不自动批量去重。每接入一个环境都应实测；缺目录、版本不符或需要确认上一代更新时停止，不能强改版本或直接删除回滚记录。首次迁移失败可使用 `rollback --root . --environment 2`；已有其他共享环境或备份不完整时工具会拒绝不安全恢复。迁移恢复与增量更新恢复是不同操作。

## 日常启动和更新

使用 `更新缓存后启动2Box.cmd` 或 `共享资源启动2Box.cmd`，先检查资源再启动 2Box。直接运行 `2Box.exe` 会跳过检查。

1. 官方更新时，先正常启动官方客户端完成更新，并确认能进入游戏。
2. 关闭官方客户端、所有多开游戏及 2Box。
3. 若提示确认上一代更新，仅在上一代已实际验收成功时运行 `确认共享资源更新.cmd`，释放该代回滚文件。
4. 使用共享启动入口，再复用原来的固定环境，不必新建账号环境。
5. 如有错误，保留提示和日志，不清空账号配置、不反复强制下载。

同版本进行标记和配置快速检查；版本变化时根据索引校验资源，只同步差异文件。同步验证成功后才提交版本信息，个人设置保持独立，配置使用游戏可识别的单行 JSON。更新被中断时关闭全部进程后使用 `恢复中断的共享更新.cmd`，保留失败记录再排查。

## 安全边界

- 正常资源来源为 `%LOCALAPPDATA%\lagrange_online_branch\Documents`，仅作为读取来源；账号数据库不作为公共资源。
- 拒绝游戏或 2Box 仍运行时更新；检查目录连接、路径边界和资源索引。
- 保留一代增量回滚，下一代更新前要求确认；单次事务预算 2GiB，超预算或基础版本不符会停止。
- 去重后的不完整迁移快照不能作为完整回滚，工具会拒绝恢复。
- 登录保持由游戏和 2Box 自行维护，不代存密码、不实现自动扫码或验证绕过。
- 共享游戏资源不能防止其他应用程序副本、临时缓存或旧备份增长，本版本不清理这些内容。
- 已有单机环境 1 至 5 的进入反馈、环境 2/3 并发进入及一次真实微更新验证；未来大版本、其他机器和其他游戏尚无兼容性保证。

## 源码与构建

源码测试请先克隆本仓库；便携下载包不包含测试文件。需要 Windows、64 位 Python 3.12 和 NTFS 可写测试目录：

```powershell
python -m unittest -v test_2box_launcher test_shared_resources test_shared_update
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

构建脚本安装锁定依赖，生成 `SharedCache.exe` 与 `_internal` 便携目录，再打包至 `dist`。只从明确列出的源码、启动入口、文档和许可证组装，不从游戏目录复制。已有依赖时可传 `-UseExistingDependencies`。输出目录已存在时停止，不自动递归清理旧产物。

源码为 MIT 许可，运行库许可见 `licenses` 和 `THIRD_PARTY_NOTICES.md`。2Box 及其 GPL-3.0 许可由原作者维护，不包含在此包中。

运行产生的 `Env`、`SharedResources`、`bin`、`log`、`repair-backups`、报告和账号文件只属于本机，禁止上传仓库或添加到公开下载包。
